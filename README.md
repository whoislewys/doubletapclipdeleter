## Installation

1. Install Remote Script
Clone this entire directory into your Remote Scripts directory. For example,

mine lives at:

`"$HOME/Music/Ableton/User Library/Remote Scripts"`

So to install this fresh, I would run the command:

`git clone git@github.com:whoislewys/doubletapclipdeleter.git "$HOME/Music/Ableton/User Library/Remote Scripts"`


2. Select DoubleTapClipDeleter control surface to activate the double tap clip delete shortcut

* Open Live settings
* Go to the "Link, Tempo & MIDI" section
* Choose an empty control surface
* Select the "DoubleTapClipDeleter" control surface from the list of options (see screenshot for what it should look like when you're done)
* Leave the "Input" and "Output" options alone
![./docs/install.png](install screenshot)

Try recording a clip, then double clicking to delete it. If it worked, you're done! If it didn't, ask Claude to fix it, idk 🤷
